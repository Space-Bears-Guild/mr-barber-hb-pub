# Pages
Every page should have a header (for navigation) and footer with the location, hours, and contact information.

- **Home**
  - Hero banner plus a blurb
  - Gallery
  - Location with an in-depth blurb (e.g. find us next to so-and-so on such-and-such street)
    - https://www.openstreetmap.org/
    - https://leafletjs.com/
  - Contact: it should have the business phone number and if the user wants to e-mail, it'll redirect to the actual Contact page with the form. Add FAQ and prices redirect buttons if the user is interested.
- **Pricing**: it may be good to have an explanation of how the cost would work.
- (Pending client confirmation) **Staff**: this is a page where people can see the current staff that work at the shop. The rationale being if people are interested in getting a haircut by so-and-so again and can ask.
- **FAQ** (maybe call it Common Questions?): list commonly asked questions. Prompt the user to call if none of the provided FAQ answer their question.
- **Contact**: for starters, this would just have the phone number. This is going to eventually house the e-mail contact form.
