## Notes

### Competitive Analysis

- Branding
  - Some stores' "theme" match the theme of their website. In other words, there is some sort of "brand".
- Website layout and content
  - Barber shops tend to have some sort of blurb, so writing content is something we'll want to do (probably helps SEO).
  - Ensure the UI is intuitive and easy to navigate. More specifically, make sure things appear to do the thing they look like do.
  - We almost certainly want a gallery so people know (1) what example cuts look like and (2) the store interior.
  - Staff/barbers page would be helpful to see who works/doesn't work there anymore.
- Store information
  - Store location should be easy to find e.g. at the bottom of the home page/footer/pretty much every page.
- Legal stuff
  - We probably need Terms & Conditions and Privacy Policy. Accessibility can probably be a end-of-project thing.

### MVP Confirmation

- Every page should have a header (for navigation) and footer with the location and contact information.
- **Home**
  - Hero banner plus a blurb
  - Gallery
  - Location with an in-depth blurb (e.g. find us next to so-and-so on such-and-such street)
    - https://www.openstreetmap.org/
    - https://leafletjs.com/
  - Contact: it should have the business phone number and if the user wants to e-mail, it'll redirect to the actual Contact page with the form. Add FAQ and prices redirect buttons if the user is interested.
- **Pricing**: it may be good to have an explanation of how the cost would work.
- **FAQ** (maybe call it Common Questions?): list commonly asked questions. Prompt the user to call if none of the provided FAQ answer their question.
- **Contact**: for starters, this would just have the phone number. This is going to eventually house the e-mail contact form.

### Sketch Plan

- We have a Figma project going. We'll start mobile first, but we should do both web and mobile sketches to be safe.
- We shall work with at least two different design styles for the website.
